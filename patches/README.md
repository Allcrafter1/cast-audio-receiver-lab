# Vibecast patch snapshots

The `vibecast-*.patch` files contain snapshots and modifications of the
[Vibecast](https://github.com/emilsvennesson/vibecast) source tree. They remain
under Vibecast's **MIT License**, including the modifications maintained for
Cast Audio Receiver Lab. Preserve the upstream copyright and the complete text
in [`../licenses/Vibecast-MIT.txt`](../licenses/Vibecast-MIT.txt).

These patches are historical/reconstruction aids. The current build uses the
exact maintained-fork revision in `config/vibecast-frontend.lock.json`.
